# Codigo De Conducta

Este repositorio es un espacio de colaboracion tecnica para una tarea
conductual con animales. Se espera que cada participante:

- trate a las personas con respeto y haga criticas sobre el codigo, no sobre
  quien lo escribio;
- documente incertidumbres, limites de validacion y resultados inesperados;
- no modifique ni ejecute hardware sin el contexto experimental adecuado;
- proteja datos de animales, operadores y resultados no publicados.

Las dudas o incidentes se reportan de forma privada al responsable
experimental del proyecto.
