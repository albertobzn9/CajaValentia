# Contributing

1. Start from a short-lived branch; do not edit a release tag.
2. Describe the intended behavioral change before changing MATLAB code.
3. Run the pure-logic test/simulation scripts first.
4. Record MATLAB version, machine, deployment path, and hardware result when
   testing a physical box.
5. Keep generated results and animal data out of Git.

Changes to outputs, pellet delivery, shock/grid control, or trial timing require
review by the experimental owner before use with animals.
